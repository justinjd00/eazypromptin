One thing you probably haven't run into yet: the usual way to stop duplicates (remember which mails were already handled) **won't catch your case**. If a supplier sends the same invoice in a second mail, that's a new mail. So I'll check for duplicates by **supplier + invoice number**: the same invoice arriving again gets skipped, and the PDF doesn't get saved a second time. If the same number turns up with a *different* amount (a corrected invoice), it gets flagged for you instead of skipped, because quietly dropping a correction would be worse than a double row.
